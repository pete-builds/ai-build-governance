# Implementation Guide

**Non-binding.** How to actually operate the model: adoption sequencing, a
worked example, deployment paths, and the procedures for the concurrent
reviews.

**Start with the [running example](02-running-example.md)** if you want the
fastest orientation. It carries one system, an agent that triages emailed
payment inquiries, through every stage end to end, and it demonstrates a case
most people misclassify.
